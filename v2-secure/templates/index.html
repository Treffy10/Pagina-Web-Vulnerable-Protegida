App Segura v2

Misma aplicación que la v1, pero con las prácticas de SecDevOps aplicadas: cada vulnerabilidad detectada en v1 fue corregida y verificada.

Ir al login Crear cuenta Ver dashboard

Objetivo

Demostrar la remediación de inyección SQL, XSS, CSRF, IDOR, subida insegura de archivos, RCE y APIs expuestas presentes en la v1.

Transporte

Servida exclusivamente sobre HTTPS (TLS) con cabeceras HSTS, CSP y cookies Secure.

Controles implementados

Sin inyección SQL

Todas las consultas usan parámetros vinculados (?) en lugar de concatenar texto.

El payload admin' -- ya no tiene efecto.

Sin XSS

Autoescape de Jinja2 activo en todas las plantillas; se eliminó el filtro |safe.

El HTML/JS ingresado se muestra como texto, nunca se ejecuta.

CSRF

Todos los formularios incluyen token CSRF validado por Flask-WTF.

Peticiones sin token válido son rechazadas (400).

Subida segura

Whitelist de extensiones, límite de tamaño y nombre de almacenamiento aleatorio (sin path traversal).

../../app.py ya no es un nombre de archivo válido.

Sin IDOR

Todo acceso a archivos valida que pertenezcan al usuario autenticado.

Cambiar el ID en la URL retorna 404, no el archivo ajeno.

API autenticada

/api/files requiere sesión activa y solo devuelve los archivos del usuario.

Sin sesión, responde con redirección al login.
Nota: Esta aplicación forma parte de un laboratorio educativo de SecDevOps (comparativa v1/v2). No expongas ninguna de las dos versiones a Internet.
