App Insegura v1

Laboratorio interactivo de seguridad. Esta aplicación muestra vulnerabilidades comunes y cómo pueden explotarse en un entorno web real.

Ir al login Crear cuenta Ver dashboard

Objetivo

Entender los riesgos de malas prácticas de desarrollo: inyección SQL, XSS, CSRF, IDOR, subida insegura de archivos y APIs expuestas.

Audiencia

Desarrolladores, analistas de seguridad y estudiantes que quieran identificar y explotar fallos en una app de ejemplo.

Vulnerabilidades disponibles

Inyección SQL

Permite manipular consultas de base de datos ingresando comillas y sentencias SQL en el login o registro.

Prueba payloads como admin' --.

XSS

Existe XSS reflejado y almacenado al ingresar HTML/JS en campos de texto y descripciones de archivos.

Envía descripciones maliciosas para ejecutar código en el dashboard.

CSRF

Los formularios POST no usan tokens CSRF, lo que permite acciones no autorizadas desde otro sitio.

Prueba ataques silenciosos a /upload y /files/<id>/delete.

Subida insegura

El sistema acepta archivos sin validar extensión ni contenido, y no protege contra path traversal.

Carga archivos con rutas como ../../app.py.

IDOR

Los archivos se acceden por ID sin validar si pertenecen al usuario autenticado.

Intenta descargar o borrar archivos de otros usuarios cambiando el ID.

API pública

El endpoint /api/files entrega todos los registros sin autenticación.

Revisa el contenido expuesto del servidor.
Cómo empezar
1Regístrate con un usuario nuevo y accede al dashboard.
2Intenta iniciar sesión con credenciales válidas y luego con un payload de SQLi.
3Sobreescribe la descripción de un archivo con HTML/JS para descubrir XSS.
4Sube un archivo con nombre malicioso y prueba a acceder a /files/<id>.
5Visita /api/files y observa la información expuesta sin autenticación.
Nota: Esta aplicación es solo para fines educativos y de prueba. No la uses en producción ni con datos reales.
